# Extension Icons

Place your icon files here with the following naming convention:
- `icon-16.png` - 16x16 pixels (for toolbar)
- `icon-48.png` - 48x48 pixels (for extension management page)
- `icon-128.png` - 128x128 pixels (for Chrome Web Store)

All icons should be in PNG format.

## Creating Icons

If you have a single source image, you can resize it to these dimensions using:
- Image editing software (Photoshop, GIMP, etc.)
- Online tools
- Command line tools like ImageMagick: `convert source.png -resize 16x16 icon-16.png`
